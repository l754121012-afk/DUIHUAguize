# Completion and Handoff

Before final response:

- run the promised validation;
- report changed files and behavior;
- state verification commands and results;
- list unresolved risks or exceptions;
- include the same-class audit result.

When the task is long or context-heavy:

- update the project handoff;
- include current status, changed files, verification, blockers and next step;
- provide a paste-ready opening prompt for the next task.
