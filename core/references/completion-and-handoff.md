# Completion and Handoff

Before final response:

- run the promised validation;
- report changed files and behavior;
- state verification commands and results;
- report actual token/cost consumption against the Task Preflight: input, output, cache-hit and
  price range when available; state the data source and explain material deviations;
- list unresolved risks or exceptions;
- include the same-class audit result.

If exact usage cannot be read from the current runtime, report a clearly labelled estimate and its
basis. Omitting the cost check is a completion defect.

When the task is long or context-heavy:

- update the project handoff;
- include current status, changed files, verification, expected vs actual cost, blockers and next step;
- provide a paste-ready opening prompt for the next task.
