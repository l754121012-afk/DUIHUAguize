# Codex App Adapter

## Rules

- Attach every created pull request to the task.
- Use the automation tool when the user asks for a reminder, recurring job, monitor or heartbeat.
- Keep periodic notifications quiet unless a meaningful change, completion, failure or user action occurs.
- Use app file-open and review panels when showing results is materially useful.
- Use inline code comments for precise review feedback instead of long quoted code.
- Keep artifact follow-ups short and actionable.
