# Default Model Policy

The Core remains model-neutral. This profile selects defaults when a provider adapter is available.

- Prefer the configured Flash/fast model for routine coding, search, tests and documentation.
- Reserve high-cost reasoning models for architecture choices, repeated parity failures and final high-risk reviews.
- Do not switch providers or reasoning tiers inside a cache-warm deliverable unless necessary.
- Use provider adapters for exact model names, routing and pricing.
